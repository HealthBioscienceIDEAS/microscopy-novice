# Image Analysis with Napari for Microscopy

A lesson teaching the fundamentals of analysing image data acquired via light microscopy experiments.

This repository serves to create a permanent redirect from the old github pages site (https://healthbioscienceideas.github.io/microscopy-novice) to the new one (https://carpentries-incubator.github.io/napari-microscopy/).
